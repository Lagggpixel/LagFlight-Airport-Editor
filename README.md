# LagFlight Airport Editor

Public installer downloads and update information. Application source is maintained separately.

## Windows

Download the Windows x64 setup executable from [Windows 0.1.1](https://github.com/Lagggpixel/LagFlight-Airport-Editor/releases/tag/airport-editor-v0.1.1).
Requires Windows 10 or later. The installer is currently unsigned. New installers upgrade the existing copy and preserve local drafts and settings.
The editor checks for updates at startup and through Help > Check for Updates, then offers the new installer download.

## macOS

Download the Apple Silicon DMG from [Releases](https://github.com/Lagggpixel/LagFlight-Airport-Editor/releases).
The current macOS build requires macOS 26 or later. Downloads are not notarized by Apple.
Signed update notices offer a manual DMG download; the editor does not automatically download or install Mac updates.
See [Apple's guidance for opening apps](https://support.apple.com/en-gb/102445).

Windows and macOS installers have platform-specific filenames. SHA-256 files accompany the downloads.
